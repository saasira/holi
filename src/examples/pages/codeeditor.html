Code editor

The editor knows no language: the colours and the completions come from a language registered by name with Holi.CodeLanguages.register(name, language), and an editor picks one with language="...". Type two letters for suggestions (or Ctrl+Space); Tab or Enter accepts. Ctrl+Enter runs the selection, or all of it; Ctrl+/ comments lines when the language has a line comment.
