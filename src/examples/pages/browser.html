Browser (node picker)

A value picker that browses a hierarchy in a modal and returns the selected node. It composes the tree (lazy children via children-loader) inside a dialog. Selecting a node and confirming sets the value, updates a hidden input, and fires a bubbling browserchange event.

Variant 1: path picker (lazy, any node selectable)

Browse from a root; children load on first expand via the children-loader.

Selected: (none)

Variant 2: leaf-only, with an initial value

Only leaf nodes may be selected (branches are not confirmable). Starts pre-filled.

Selected: /content/data/students/naresh

Variant 3: flat list (single level — e.g. a model picker)

A root whose children are all leaves acts as a flat chooser.
